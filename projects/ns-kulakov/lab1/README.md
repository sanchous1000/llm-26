
# Лабораторная работа №1

## Описание задания

   
Проанализировать работу трёх моделей (см. ниже) на трёх промптах:

```
Подготовь краткое экспертное заключение о том, почему статистически значимый результат не обязательно означает практическую значимость. Приведи пример из исследования образовательных технологий. Объём — до 200 слов.
```
```
Классифицируй описание исследования по одной из меток: STATISTICAL_ERROR, METHODOLOGY_ISSUE, REPORTING_ISSUE, NO_OBVIOUS_ISSUE. Авторы проверили десять гипотез, сообщили только об одной с p = 0.04 и не упомянули остальные проверки.
```
```
Из описания исследования извлеки размер выборки, группы, метод анализа, p-value, эффект и основные ограничения. Верни валидный JSON. Не придумывай отсутствующие значения. В эксперименте участвовали 120 студентов, разделённых на контрольную и экспериментальную группы по 60 человек. Средние результаты составили 71 и 77 баллов. Авторы применили независимый t-тест и получили p = 0.018.
```

Сравнить длину ответа в токенах LLM, точность/адекватность под задачу, стабильность/детерминизм, повторяемость, наличие фактических ошибок/галлюцинаций


## Использованные технологии и модели
- LLM: `qwen3:4b-instruct-2507-q4_K_M`, `llama3.2:3b`, `mistral:7b-instruct`
- Библиотеки: `requests`, `pandas`

   ## Выводы

### 1. Сравнение моделей по качеству и скорости
- Qwen3 4B Instruct показала наиболее надёжный результат на выбранных заданиях: 9/9 правильных классификаций P2 и 9/9 синтаксически корректных JSON-ответов P3. Для P3 получено всего 2 уникальных текста при 9 сочетаниях настроек; в восьми случаях JSON одинаковый, в девятом несколько иначе описаны группы. Важно, что значение «эффект»: 6 в её JSON — это вычисляемая разность средних (77 − 71), а не стандартизированный размер эффекта; последний без дисперсий или стандартных отклонений вычислить нельзя.
- Llama 3.2 3B генерировала токены быстрее остальных (81.0 токенов/с в среднем), но качество структурированных ответов ниже: 2/9 правильных меток P2 и только 1/9 валидных JSON для P3. Типичные нарушения: текст вокруг JSON, Markdown-блоки, синтаксические ошибки, смешение языков и домыслы о параметрах исследования.
- Mistral 7B Instruct успешно вернула валидный JSON 7/9 раз, но не указала целевую метку REPORTING_ISSUE ни в одной из девяти классификаций P2: чаще выбиралась METHODOLOGY_ISSUE. Синтаксически корректные JSON-ответы также могут содержать выдуманные сведения: например, для P3 при temperature=0.7, top_k=40 указано standard_deviation_pooled: 15, хотя такое значение в условии отсутствует. При temperature=1.0 два из трёх JSON не разбираются из-за недопустимых конструкций, включая вычисления и комментарии внутри JSON.
В P1 все 27 ответов укладываются в лимит 200 слов при подсчёте по пробелам; при этом тексты заметно различаются по формулировкам.

### 2. Влияние temperature и top_k
- Для Qwen корректность P2 (3/3 на каждой температуре) и валидность JSON P3 (3/3) не изменились. Средняя длина ответа в зависимости от температуры колебалась слабо. Это признак устойчивости решения на данных тестах.
- Для Llama правильная метка P2 встретилась 1/3 раз при 0.2, 1/3 при 0.7 и 0/3 при 1.0; JSON P3 оставался невалидным в шести прогонах при 0.2 и 0.7 (все 6), а при 1.0 валидным был 1/3. Изменение параметров не даёт очевидного устойчивого улучшения.
- Для Mistral P2 остался некорректным при всех настройках; JSON P3 был валидным 3/3 при 0.2, 3/3 при 0.7 и 1/3 при 1.0. Это наблюдаемое ухудшение структурного формата на высокой температуре.
По top_k также наблюдаются изменения в длине ответа, но они не монотонные и зависят от модели и промпта.
