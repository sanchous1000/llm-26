# Тестовые запросы

Три промпта, которые уходили в каждую модель без изменений.

## P1. Генерация: вежливое письмо

Напиши вежливое деловое письмо клиенту компании «СеверТех».
Факты (нельзя выдумывать другие):

- поставка серверов задерживается на 5 рабочих дней из-за логистики;
- новая дата прибытия — пятница следующей недели;
- компенсация — скидка 7% на следующую услугу сопровождения.

Требования:

- 120–180 слов;
- обращение на «вы», без канцелярита и без извинений «за любые неудобства» как единственной сути;
- не добавляй телефон, email, ФИО менеджера и трек-номер, если их нет во входных фактах;
- закончи письмом с предложением подтвердить получение.

## P2. Классификация обращений

Метки: `["Биллинг", "Техподдержка", "Продажи"]`

Классифицируй каждое обращение ровно одной меткой из списка:
["Биллинг", "Техподдержка", "Продажи"]

Правила:

- ответь ТОЛЬКО JSON-массивом вида [{"id": 1, "label": "..."}, ...];
- никаких комментариев, markdown и текста вокруг JSON;
- если сомневаешься, выбери наиболее вероятную метку, не выдумывай новые.

Обращения:

1. «Мне дважды списали оплату за тариф Про, верните деньги.»
2. «VPN на ноутбуке после обновления не подключается, ошибка 809.»
3. «Нужно 30 лицензий для отдела продаж, есть скидка при годовой оплате?»
4. «Счёт за август не пришёл на почту, пришлите повторно.»

## P3. Извлечение полей и краткое резюме

Из описания товара извлеки поля и сделай краткое резюме.

Описание:
«Беспроводные наушники Aurora X2. Драйвер 40 мм, Bluetooth 5.3, ANC до 32 дБ, до 36 ч работы с кейсом, вес 255 г, цвет графит. Цена 8 990 ₽. В комплекте USB-C кабель и чехол. Гарантия 24 месяца. Страна бренда — не указана.»

Верни ТОЛЬКО JSON-объект со ключами:

```json
{
  "name": "строка",
  "price_rub": "число",
  "bluetooth": "строка",
  "anc_db": "число",
  "battery_hours": "число",
  "weight_g": "число",
  "warranty_months": "число",
  "color": "строка",
  "country": "строка или null если не указано",
  "summary": "ровно 2 предложения на русском"
}
```

Не выдумывай характеристики, которых нет в тексте. Никакого текста вокруг JSON.
