# Лабораторная работа №1

## Описание задания

Развёрнуты три LLM из разных семейств в локальной Ollama (доступен OpenAI-совместимый REST `/v1`). Подготовлены три промпта на русском под разные типы задач:

- **P1** — генерация: вежливое деловое письмо с заданными фактами;
- **P2** — классификация обращений по фиксированным меткам `["Биллинг", "Техподдержка", "Продажи"]`;
- **P3** — извлечение полей из описания товара и краткое резюме.

Каждая модель отвечает на каждый промпт в двух режимах: **A_base** (дефолты Ollama) и **B_tune** (изменены четыре гиперпараметра). Всего 18 прогонов. По ним сравниваются длина ответа, точность, стабильность, повторяемость, ошибки, время отклика, токены и скорость.

## Использованные технологии и модели

- LLM (Ollama): `qwen3:8b`, `gemma3:4b`, `mistral:7b`
- Движок: Ollama, эндпоинт `/api/chat` (там отдаются `prompt_eval_count`, `eval_count` и длительности)
- Python 3.13, `requests`, `pandas`, `matplotlib`

Гиперпараметры режима B_tune относительно дефолтов Ollama:


| Параметр         | A_base | B_tune |
| ---------------- | ------ | ------ |
| `temperature`    | 0.8    | 0.1    |
| `top_k`          | 40     | 20     |
| `top_p`          | 0.9    | 0.7    |
| `repeat_penalty` | 1.1    | 1.25   |


Потолок `num_predict` не ставился: у `qwen3:8b` короткий лимит расходуется на скрытое рассуждение, и видимый ответ получался пустым.

## Результаты работы

Файлы в `results/`:

- `prompts.md` — тексты трёх промптов;
- `responses.md` — все 18 ответов с метриками;
- `analysis.md` — подробный анализ влияния гиперпараметров;
- `charts.png` — графики длины, времени и скорости.

Средние по всем моделям и промптам:


| Метрика                   | A_base | B_tune |
| ------------------------- | ------ | ------ |
| Длина ответа, tok         | 306.1  | 274.1  |
| Время отклика, s          | 18.24  | 8.56   |
| Скорость генерации, tok/s | 39.56  | 34.71  |
| Accuracy P2 и P3          | 1.00   | 0.96   |


Точность по задачам: P3 извлекается верно у всех моделей в обоих режимах, выдуманной страны нет. В P2 `mistral:7b` в режиме B_tune оборвал JSON и пропустил четвёртое обращение.

## Выводы

- Сужение сэмплинга и более высокий `repeat_penalty` немного укорачивают ответы (306 → 274 токена) и слегка снижают скорость генерации, но точность не повышают.
- Разница во времени отклика (18 → 9 с) связана с загрузкой весов на первом запросе каждой модели (`load_duration` 20–33 с), а не с гиперпараметрами. Скачок скорости токенизации промпта объясняется кэшем.
- Основные проблемы в P1: письма короче заданных 120–180 слов, плейсхолдеры у `qwen3:8b`, неверный адресат у `gemma3:4b`, сломанные русские слова и выдуманные детали у `mistral:7b`.
- Повторов текста почти нет: доля повторённых 3-грамм не выше 0.06.



## Инструкция по запуску

1. Запустить Ollama и скачать модели: `ollama pull qwen3:8b`, `ollama pull gemma3:4b`, `ollama pull mistral:7b`.
2. Установить зависимости: `pip install -r source/requirements.txt`.
3. Запустить скрипт: `python source/main.py`.
4. Результаты появятся в каталоге `results/`.
