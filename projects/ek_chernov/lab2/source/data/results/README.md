# Результаты экспериментов

Оценка запускается с обязательным названием эксперимента:

```bash
uv run python -m source.scripts.evaluate_retrieval --experiment baseline
```

Каждый запуск сохраняется отдельно:

```text
runs/<UTC timestamp>_<experiment>/
├── result.json
└── report.md
```

- `result.json` повторяет формат прежнего `retrieval_metrics.json`;
- `report.md` содержит таблицу и вывод только для этого запуска;
- старые каталоги запусков не перезаписываются.

В корне каталога автоматически пересобираются:

- `leaderboard.json` — компактный индекс запусков и агрегированных метрик;
- `leaderboard.md` — отдельный раздел и таблица для каждого запуска;
- `latest.json` — указатель на последний хронологический запуск;
- `best_experiment.json` — запуск и конфигурация, выбранные для RAG.

В `leaderboard.md` максимизируются P@5, R@5, P@10, R@10, MRR и
Fact Recall. Для времени поиска, времени генерации и числа чанков выбирается
минимум. Лучшие значения выделяются жирным; при равенстве выделяются все
совпавшие значения.
